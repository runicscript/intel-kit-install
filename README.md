# intel-kit-install

这是 **intel-kit 的公开安装仓库**（只有安装脚本和说明），不是产品本身。产品需购买后获得**激活码**才能下载安装。

## 怎么装

把本仓库链接发给你的 AI 助手，说：

> 按 SETUP.md 帮我装

助手会按 `SETUP.md` 逐步检查环境、运行 `bootstrap.py`、采访你的需求并完成首次配置。

## 离开本机的数据

安装时会向下载服务发送：

- 激活码（许可证密钥）
- 设备指纹的哈希（不是原始机器信息）
- 当前/请求的版本号

详见 `docs/API.md` 与 `EULA.md`。

## 卸载

确认不再需要后：

```bash
rm -rf ~/.intel-kit
```

（若设置了 `INTEL_KIT_HOME`，删除该目录。）
